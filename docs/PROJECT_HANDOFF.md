# «Формы мысли» — handoff для сборки

## 1. Что собираем

«Формы мысли» — цифровая игровая платформа для детей, родителей и взрослых. Она помогает придумывать, замечать, соединять и развивать идеи через короткие задания и мини-игры.

Платформа является частью единой системы детских подарков ПравоТех. Цифровая игра знакомит с персонажами и механиками, а физический подарок продолжает этот опыт в реальной жизни.

Главная формула:

> придумал в игре → создал сам → получил физическую форму → продолжил использовать в жизни.

## 2. Персонажи

- **Искра** — жёлтая графическая звезда. Отвечает за воображение, новые идеи и неожиданные варианты.
- **Фокус** — фиолетовая графическая лучистая форма. Помогает замечать детали и выделять главное.
- **Связь** — голубая графическая стрелка. Соединяет предметы, мысли и людей.

Персонажи в игре должны оставаться графическими, без текстильной фактуры, швов и эффекта мягкой игрушки. Физические подарки используют их цвета, символы и визуальный язык, но не обязаны буквально повторять персонажей.

## 3. Игровая платформа

В текущем прототипе 11 заданий:

1. Соедини несоединимое.
2. Две мечты.
3. Найди предметы в комнате.
4. Поймай идеи.
5. Найди общее.
6. Рядом, но незаметно.
7. Твоя идея + ИИ.
8. Сохрани момент.
9. Выбери главное.
10. Мемо: найди пару.
11. Маленькая и большая — задача в духе ТРИЗ.

Активности не ограничиваются письмом. В них есть поиск, наблюдение, память, реакция, выбор, устный разговор, свободное придумывание и решение противоречий.

### Режимы

- **Вместе с родителем** — короткие задания, меньше пар и предметов, отсутствие таймера, взрослый читает и помогает.
- **Я сам** — самостоятельная игра с подсказками, среднее количество элементов и мягкие ограничения по времени.
- **Я взрослый** — более сложные условия, больше пар и предметов, короткие таймеры, задания для самостоятельного прохождения или совместной игры с ребёнком.

На этой же платформе могут играть взрослые: отдельно, вместе с ребёнком или как участники семейной активности. Взрослый может пройти задания, создать собственную форму мысли и сравнить свои решения с детскими.

### Игровой путь

1. Пользователь знакомится с героями.
2. Выбирает режим.
3. Выбирает персонажа-помощника.
4. Открывает ящички шкатулки в любом порядке.
5. Сохраняет ответы и открытия в коллекцию.
6. После шести заданий открывается конструктор собственного героя.
7. Пользователь выбирает форму, цвет, имя и суперсилу.
8. Карточку героя можно скачать в PNG.

Рейтинг, соревнование и единственно правильные ответы не используются. Ошибка должна быть поводом попробовать другой вариант.

## 4. Подарки как продолжение игры

### Вариант 1 — «Идея всегда с собой»

Бутылка, фирменные стикеры, небольшой брелок-компаньон и сертификат Ozon на 1000 рублей. Стикеры позволяют персонализировать бутылку, рюкзак, пенал или другие вещи. Связь с игрой — через героев, символы и фразы.

Ключевая фраза: **«Идеи можно брать с собой».**

### Вариант 2 — «Мемо, которое продолжается»

Мешочек и карточки мемо в фирменном стиле. Часть карточек может быть незавершённой: ребёнок дорисовывает эмоции, детали, узоры и новых персонажей. На обороте можно размещать короткие задания: «добавь Искре суперсилу», «придумай, что заметил Фокус», «соедини две карточки».

Это физическое продолжение цифрового мемо: игра начинается с готовых карточек, но ребёнок постепенно создаёт свою версию.

Ключевая фраза: **«Игра начинается с готовых карточек, а заканчивается тем, что придумал ты».**

### Вариант 3 — «Собери свою форму мысли»

Набор для сборки подвеса: мини-сумочка, буквы, карабин и декоративные элементы, а также сертификат Ozon на 1000 рублей. Ребёнок собирает аксессуар, выбирает имя или слово и придумывает его суперсилу.

Это прямое физическое продолжение конструктора героя в игре.

Ключевая фраза: **«У каждой мысли может появиться своя форма».**

## 5. Принцип соучастия

Подарок не должен быть полностью готовым и одинаковым для всех. Ребёнок получает основу, которую может изменить:

- выбрать героя;
- дорисовать карточки;
- собрать подвес;
- выбрать буквы и цвет;
- придумать имя и суперсилу;
- самостоятельно выбрать дополнительную вещь по сертификату.

Для родителей можно добавить карточку с вопросами и подсказками, чтобы продолжить активность без экрана.

## 6. Визуальные правила

- Яркая, дружелюбная графика с крупными простыми формами.
- Основные цвета: жёлтый/оранжевый для Искры, фиолетовый для Фокуса, голубой для Связи.
- Белые и светлые фоны, фиолетовый как основной акцент интерфейса.
- Стикерная эстетика, карточки, стрелки, звёзды, соединения и следы движения.
- Достаточно свободного места для детского рисунка.
- Не использовать текстильную фактуру для игровых персонажей.
- Не перегружать дизайн мелкими деталями и большим количеством начертаний.

## 7. Структура текущего проекта

```text
formy-mysli/
├── dist/
│   ├── index.html              # основная статическая игра
│   └── assets/
│       ├── spark.png           # Искра
│       ├── focus.png           # Фокус
│       └── link.png            # Связь
├── docs/
│   ├── PROJECT_HANDOFF.md      # этот handoff
│   ├── image-metadata.json     # метаданные графики
│   ├── image-prompts.json      # промпты графики
│   └── preview.jpg             # превью
├── .openai/hosting.json        # конфигурация Sites
├── dev-server.mjs              # локальный сервер и мобильный QA-маршрут

```

Отдельная автономная версия с графикой внутри одного HTML-файла хранится в Library как `formy_mysli_prototype.html` и доступна локально в рабочей копии проекта.

## 8. Локальный запуск

```bash
npm run dev
```

Основной адрес: `http://localhost:4173/`.

Для мобильной проверки используется `http://localhost:4173/__qa_mobile`. Маршрут создаёт iframe шириной 390 px и не входит в публикацию.

Проверка JavaScript:

```bash
node --check <extracted-script.js>
```

## 9. Данные и ограничения прототипа

Прогресс хранится локально в браузере в `localStorage` с ключом `thoughtFormsState`.

Сохраняются:

- выбранный персонаж;
- выбранный режим;
- выполненные задания;
- ответы и черновики;
- выбранные предметы;
- созданный пользовательский герой.

Внешний сервер, база данных, аналитика, авторизация, синхронизация между устройствами и живой вызов ИИ не используются. Примеры в задании «Твоя идея + ИИ» заранее подготовлены.
