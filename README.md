# Формы мысли — Шкатулка идей

Игровой прототип ПравоТех для детей и родителей. Искра — жёлтая звезда, Фокус — фиолетовая лучистая форма, Связь — голубая стрелка. Все герои в игре графические, без ткани и швов.

Самостоятельная статическая страница находится в `dist/index.html`, графика — в `dist/assets`. Серверная часть, внешние шрифты, аналитика и сетевой ИИ не используются. Прогресс, черновики, ответы и созданный герой сохраняются в localStorage этого браузера с ключом `thoughtFormsState`. Старый формат сохраняет выполненные задания и выбор героя; отсутствовавшие в нём ответы восстановить нельзя.

В игре 9 заданий, включая две мини-игры, коллекция ответов и конструктор, доступный после шести выполненных заданий. Карточку героя можно скачать в PNG.

Для локальной разработки: `npm run dev`. В управляемой среде используется `sites-preview start <путь>`. Маршрут `/__qa_mobile` существует только в dev-сервере для просмотра в iframe шириной 390 px; он не входит в статическую публикацию.
