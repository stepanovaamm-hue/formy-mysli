# Формы мысли — Шкатулка идей

Игровой прототип ПравоТех для детей и родителей. Искра — жёлтая звезда, Фокус — фиолетовая лучистая форма, Связь — голубая стрелка. Все герои в игре графические, без ткани и швов.

Проект создаётся как новогодний подарок для детей сотрудников и их семей: цифровая игра, физический набор и совместные активности складываются в один праздничный опыт.

Самостоятельная статическая страница находится в `dist/index.html`, графика — в `dist/assets`. Серверная часть, внешние шрифты, аналитика и сетевой ИИ не используются. Прогресс, черновики, ответы и созданный герой сохраняются в localStorage этого браузера с ключом `thoughtFormsState`. Старый формат сохраняет выполненные задания и выбор героя; отсутствовавшие в нём ответы восстановить нельзя.

В игре 11 заданий, включая мемо, поиск предметов, игру на реакцию и задания в духе ТРИЗ. Есть коллекция ответов и конструктор, доступный после шести выполненных заданий. Карточку героя можно скачать в PNG.

Для игры предусмотрены три режима: «Вместе с родителем», «Я сам» и «Я взрослый». Режим меняет количество пар и предметов, наличие таймера, подсказки и сложность задания. Взрослый может играть самостоятельно или вместе с ребёнком.

Игра является частью общей концепции «Формы мысли»: цифровые активности продолжаются в физических подарках — бутылке со стикерами, дорисовываемом мемо или наборе для сборки собственного подвеса. Все варианты используют графический фирменный язык персонажей и принцип соучастия.

Для локальной разработки: `npm run dev`. В управляемой среде используется `sites-preview start <путь>`. Маршрут `/__qa_mobile` существует только в dev-сервере для просмотра в iframe шириной 390 px; он не входит в статическую публикацию.
